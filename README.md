
# ClassHub

ClassHub is a web platform where students can discover and register for classes offered by freelance teachers and small training centers.

## How to Run (M1 Frontend Prototype)

### Requirements
- Node.js 24
- npm

### 1. Install Dependencies

```bash
cd web
npm install
```

### 2. Start the Mock API

Inside the `web` folder, run:

```bash
npm run api
```

The mock API runs at http://localhost:3000.

### 3. Start the Frontend

Open another terminal inside `web` and run:

```bash
npm run dev
```

Open http://localhost:5173 to view ClassHub.
